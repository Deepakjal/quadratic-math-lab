Reading the equation

In ax² + bx + c = 0, a multiplies x², b multiplies x, and c is the constant number. Keep the sign with its number: in x² − 5x + 6 = 0, b = −5.

Symbols

x² means x multiplied by itself. √ means square root. ± means calculate once using plus and again using minus.

The discriminant

D = b² − 4ac. If D is positive there are two real answers; if D is zero there is one repeated answer; if D is negative there are no real-number answers.
